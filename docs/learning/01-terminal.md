# 1단계 · 터미널 기본기

> 실습 로그: [`docs/logs/01-terminal.log`](../logs/01-terminal.log)

## 배운 개념

### 터미널 / 셸 / 프롬프트

- **터미널**: 글자를 입력받는 창(껍데기)
- **셸(shell)**: 그 안에서 명령을 실제로 해석하는 프로그램. 이 환경은 `zsh`
- **프롬프트 `$`**: "명령을 기다리는 중"이라는 표시.
  로그에서 `$`로 시작하는 줄이 **내가 친 명령**, 그 아래가 **컴퓨터의 대답**이다.

### 명령어의 구조

```
ls    -la    ~/codyssey
↑     ↑      ↑
명령  옵션   대상(인자)
```

옵션은 `-`로 시작하고 동작을 바꾼다. `-l`(자세히) + `-a`(숨김 포함) = `-la`로 합쳐 쓸 수 있다.

### 경로(Path) — 이 단계의 핵심

| 종류 | 기준 | 예시 |
|---|---|---|
| **절대경로** | 최상위 `/` | `/Users/nika.dev02147536/codyssey/practice/src/hello.txt` |
| **상대경로** | **현재 위치(`pwd`)** | `./src/hello.txt` |

기호 3개:

| 기호 | 의미 |
|---|---|
| `.` | 현재 폴더 |
| `..` | 상위 폴더 |
| `~` | 내 홈 폴더 |

**실습으로 확인한 것**: 같은 파일 하나를 두 방식으로 가리킬 수 있고, `cd`로 이동하면 **상대경로만 달라진다**.

```
practice 에서 :  cat ./src/hello.txt
src 로 이동하면:  cat ./hello.txt          ← 같은 파일인데 표기가 달라짐
                 cat ../backup/hello_backup.txt
```

| | 절대경로 | 상대경로 |
|---|---|---|
| 내가 이동하면? | **안 변함** | **변함** |
| 장점 | 어디서 실행해도 동일 | 짧고, 프로젝트째 옮겨도 유지 |
| 쓰는 곳 | 시스템 설정, 크론잡 | 프로젝트 내부 코드, Dockerfile |

### `ls -l` 한 줄 읽는 법

```
drwxr-xr-x   4   nika.dev02147536  nika.dev02147536  128   7 28 15:47   backup
└─────┬───┘  │   └──────┬───────┘  └──────┬───────┘  └┬┘   └───┬────┘   └─┬──┘
   권한     링크수     소유자              그룹      크기   수정시각      이름
```

맨 앞 1글자: `d` = 디렉토리, `-` = 일반 파일. 나머지 9칸이 2단계에서 다룰 권한.

## 헷갈리기 쉬운 지점

### 1. `ls -la`에 나오는 `.` 과 `..` 은 파일이 아니다

자기 자신(`.`)과 부모 폴더(`..`)를 가리키는 **바로가기**다.
이름이 `.`으로 시작하면 숨김 취급이라 `-a` 없이는 안 보인다. (`.gitignore`가 안 보이던 이유)

### 2. `>` 와 `>>` 의 차이 — 실수하면 파일이 날아간다

```sh
echo "line1" >  hello.txt    # 덮어쓰기 (기존 내용 삭제!)
echo "line2" >> hello.txt    # 이어붙이기
```

`echo`는 원래 화면에 글자를 출력하는 명령인데, `>`를 붙이면 **출력을 화면 대신 파일로 보낸다**(리다이렉션).

### 3. 리눅스에는 "이름 변경" 명령이 따로 없다

`mv`(move, 옮기기)로 같은 폴더 안에서 다른 이름으로 옮기면 그게 곧 이름 변경이다.
**이름도 위치 정보의 일부**로 본다.

### 4. `rm`은 휴지통을 거치지 않는다

즉시 삭제되고 복구가 안 된다. 특히 `rm -rf`는 신중하게.

### 5. `mkdir -p`의 `-p`

중간 폴더가 없으면 알아서 다 만들어 준다.
`-p` 없이 `mkdir ~/codyssey/practice/src`를 치면 "codyssey가 없다"며 실패한다.

## 실습 결과물

```
~/codyssey/practice/
├── src/hello.txt              (line1, line2)
└── backup/hello_backup.txt    (복사본)
```

## 스스로 설명할 수 있어야 하는 것 (과제 목표)

> 절대경로는 `/`부터 시작하는 전체 주소라 어디서 실행해도 같은 곳을 가리키고,
> 상대경로는 현재 위치 기준이라 `cd`로 이동하면 같은 파일도 다른 표기
> (`./src/hello.txt` → `./hello.txt`)가 된다.
