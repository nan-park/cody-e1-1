## 단계별 한 줄 요약

- **0단계** — 이 미션은 성능이 아니라 **환경 불일치**를 푸는 작업이다.
- **1단계** — 절대경로는 어디서 실행해도 같은 곳, 상대경로는 **내가 이동하면 달라진다**.
- **2단계** — `r/w/x = 4/2/1`을 3묶음으로 더한 게 숫자 표기. 단 **디렉토리에서는 의미가 바뀐다**(`x` = 진입).
- **3단계** — `--version`은 CLI 확인일 뿐, **데몬 확인은 `docker info`의 `Server:` 섹션**으로 한다.
