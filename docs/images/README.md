# 접속 증거 스크린샷

미션 요구사항상 **브라우저 주소창(포트 포함)과 응답 화면이 함께 보이는** 캡처가 필요하다.
아래 파일명으로 이 폴더에 넣으면 README와 학습 일지에서 링크된다.

| 파일명 | 무엇을 캡처할지 | 확인 주소 |
|---|---|---|
| `browser-8080.png` | 포트 매핑 접속 ① | http://localhost:8080 |
| `browser-8081.png` | 포트 매핑 접속 ② (같은 이미지, 다른 포트) | http://localhost:8081 |
| `browser-env.png` | 환경변수 주입 결과 (선택) | http://localhost:8082/env |
| `vscode-github.png` | VSCode GitHub 연동 화면 (8단계) | – |

## 캡처 방법 (macOS)

- `Cmd + Shift + 4` → 영역 지정 캡처
- `Cmd + Shift + 4` → `Space` → 창 전체 캡처

## 주의

- **주소창이 반드시 보이게** 찍을 것 (포트 번호가 증거)
- 토큰, 비밀번호, 인증 코드 등 민감정보가 화면에 없는지 확인 후 저장할 것
